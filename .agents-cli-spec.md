# CaféMesh AI agent requirements

- Python package `cafemesh`; Google ADK agents: concierge, taste_safety, visit_order, ops_owner.
- Gemini calls are optional and server-side. Missing credentials must expose deterministic demo status, never live status.
- All tools are narrow functions over validated app services. No model tool can confirm customer orders, execute operations, change safety profiles, or access secrets.
- Safety eligibility, prices, stock, opening, order transitions, and approval are backend invariants.
- Agent activity records public tool name, evidence identifiers, latency, status, and a concise outcome; never hidden reasoning or sensitive prompts.
- Structured menu data is authoritative in SQLite; do not add RAG.

This file is a project specification only. Google Agents CLI recognizes its own scaffold/configuration conventions; no special behavior for this filename was found in its current project-structure guidance.
